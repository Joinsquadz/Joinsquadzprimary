## Part 2: Extend the coach tour to Trips and Vault

The current sequence (in `TipsContext.tsx` / `TipCoachMark.tsx`) is: Squad event → Availability → Squad chat → Moments ring → Vibe Feed. Insert two new steps:

1. **Trip step** — insert immediately after the squad event step. Anchor it to the "Plans" section in squad detail (the one with the `No plans yet · start an event or a trip` empty state, per `app/squad/[id].tsx`), or to the most reliable measurable target for trip-starting intent if that empty state isn't a stable anchor. Copy: **"Plan a trip here too"**
2. **Vault step** — insert immediately after the Vibe Feed step. Anchor it to the `Squad Vault` / `View vault · private memories` row in squad detail. Copy: **"Photos land in your Vault"**

Final sequence: Squad event → Trip → Availability → Squad chat → Moments ring → Vibe Feed → Vault.

Use the same overlay mechanics, controls (`Next` / `Done` / close), and anchor-measurement approach already used for the existing steps. Don't build a parallel system.
